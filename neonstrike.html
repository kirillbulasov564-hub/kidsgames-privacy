Политика конфиденциальности игры «Неон Страйк»

Дата вступления в силу: 21 октября 2026 г. Обновлено: 06.11.2026 (версия 1.2.3).

Игра «Неон Страйк» (ru.bulashov.neonstrike) разработана Булашовым Кириллом. Эта политика объясняет, какие данные обрабатывает игра.

Какие данные собираются

Сама игра не собирает, не продаёт и не передаёт разработчику персональные данные. Регистрация не нужна. Начиная с версии 1.2.2 в игре есть реклама Рекламной сети VK (ООО «ВК»), а с версии 1.2.3 — также Рекламной сети Яндекса (ООО «Яндекс»), поэтому игре нужен доступ к интернету (разрешения INTERNET и ACCESS_NETWORK_STATE). Без интернета игра работает полностью, просто реклама не показывается, а награды за видео выдаются в подарок.

Данные на устройстве

На вашем устройстве (в локальном хранилище приложения) сохраняются только игровой прогресс: рекорды и личные результаты, монеты, открытые герои и улучшения, достижения, ежедневные задания, серия входов, испытание недели, незаконченный забег (чтобы продолжить с того же места), сведения о запросе оценки, а также настройки (музыка, контрастность, вибрация, эффекты, язык). Для ежедневных заданий и испытания недели игра использует дату на устройстве; дата никуда не передаётся. Эти данные никуда не отправляются и удаляются вместе с приложением или при очистке его данных.

Разрешения

Игра использует разрешения на доступ к интернету и состоянию сети (для рекламы и для работы служб RuStore: оценка и служебные метрики SDK) и на вибрацию (короткий отклик при ударах, её можно выключить в настройках). SDK оценки RuStore также добавляет разрешение на получение события загрузки устройства (RECEIVE_BOOT_COMPLETED) для своей служебной службы метрик. Игра не запрашивает доступ к камере, микрофону, местоположению, контактам или файлам.

В настройках игры есть ссылки на эту политику и на почту разработчика. Они защищены проверкой для взрослых (нужно решить пример на умножение) и открываются только во внешнем браузере или почтовом приложении; сама игра при этом никаких данных не передаёт.

Реклама

Реклама показывается с помощью SDK двух рекламных сетей: Рекламной сети Яндекса (Yandex Mobile Ads SDK 8.6.0, с версии 1.2.3) и Рекламной сети VK (myTarget 5.52.5, с версии 1.2.2). Сначала запрашивается реклама Яндекса, если её нет — реклама VK. Форматов два, места и частота показа одинаковы для обеих сетей.

Видео с наградой — только по желанию игрока, по нажатию кнопки:

  • продолжить забег после поражения («Второй шанс за видео»);
  • открыть бесплатный сундук («Бесплатно за видео»).

Награда выдаётся после досмотра ролика. Если рекламу загрузить не удалось (нет сети или подходящих объявлений), награда выдаётся без рекламы.

Полноэкранная реклама — только после окончания забега, при нажатии «Играть» или «Меню», не чаще одного раза в 2,5 минуты, не раньше чем через 2,5 минуты после запуска, никогда во время забега и в обучении.

Баннеров нет. Обе сети работают в детском режиме: до загрузки любой рекламы игра сообщает SDK, что пользователь может быть ребёнком (VK: MyTargetPrivacy.setUserAgeRestricted(true); Яндекс: setAgeRestricted(true) и флаг AGE_RESTRICTED_USER в манифесте), не даёт согласия на обработку персональных данных и отключает определение местоположения. Поэтому показывается только неперсонализированная реклама, рекламный идентификатор (Advertising ID) не используется, разрешение на него из приложения удалено, сервис аналитики MyTracker не подключён. Для доставки рекламы и подсчёта показов SDK могут получать технические данные, необходимые для показа объявления: IP-адрес, модель и версию ОС устройства, язык, сведения о сети и факте показа или нажатия. В составе SDK Яндекса есть служебный компонент AppMetrica; отдельная аналитика приложения через него не включена (APPMETRICA_EASY_INTEGRATION_ENABLED=false, setAppAdAnalyticsReporting(false)). Эти данные обрабатывают ООО «ВК» и ООО «Яндекс» по своим правилам: политика конфиденциальности myTarget, документы Рекламной сети VK, политика конфиденциальности Яндекса, условия использования Yandex Mobile Ads SDK. Разработчик эти данные не получает.

Оценка в RuStore и служебные метрики SDK

С версии 1.2.3 приложение использует официальный RuStore Review SDK (ru.rustore.sdk:review:10.5.1) для показа системного окна оценки приложения. Оценка запрашивается ненавязчиво (после нескольких запусков и завершения забега, не чаще раза в несколько дней, без наград за оценку). Если системное окно недоступно, игра может предложить открыть страницу приложения в RuStore. Вместе с Review SDK подключается служебный модуль метрик RuStore (ru.rustore.sdk:metrics): он может получать технические данные об устройстве и работе SDK для стабильности и статистики RuStore. Разработчик не получает и не обрабатывает эти данные сам. Подробности — в документах RuStore / VK: справка для разработчиков RuStore, RuStore Review SDK.

Покупки и аналитика

В игре нет встроенных покупок. Сторонние аналитические сервисы не используются (кроме служебных функций рекламных SDK и SDK оценки RuStore, описанных выше).

Возраст

Игра имеет возрастную маркировку 6+. Разработчик не собирает данные о детях и других пользователях; реклама настроена в детском режиме без персональных данных и без персонализации. Нажатие на рекламу может открыть сайт или магазин приложений; если ребёнок играет один, интернет можно выключить — игра полностью работает без него.
