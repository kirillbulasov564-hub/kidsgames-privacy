Политика конфиденциальности приложения «Улётные санки»

Дата вступления в силу: 05.11.2026

Приложение «Улётные санки» (пакет ru.bulashov.uletsanki) разработано Булашовым Кириллом (далее — разработчик). Эта политика объясняет, какие данные использует приложение.

1. Какие данные собираются

Разработчик не собирает, не передаёт и не продаёт персональные данные. Регистрация и вход не требуются. Отдельной аналитики приложения (в том числе через AppMetrica) нет.

2. Данные на устройстве

Игровой прогресс (монеты, уровни улучшений, рекорд, выполненные цели, ежедневные задания, серия входов, открытые персонажи и санки, сведения о запросе оценки) и настройки (музыка, тряска экрана) хранятся только локально на вашем устройстве и никуда не отправляются разработчиком. Эти данные удаляются кнопкой «Сбросить прогресс» в настройках игры, очисткой данных приложения или его удалением.

3. Разрешения

Приложение использует разрешения на доступ к интернету и состоянию сети — для показа рекламы и для работы служб RuStore (оценка и служебные метрики SDK). Без интернета игра работает полностью: прогресс, задания, коллекция и награды доступны, просто реклама и окно оценки RuStore не показываются. SDK оценки RuStore также добавляет разрешение на получение события загрузки устройства (RECEIVE_BOOT_COMPLETED) для своей служебной службы метрик. Приложение не запрашивает доступ к камере, микрофону, контактам, местоположению или файлам.

4. Реклама

В игре есть реклама двух рекламных сетей: с версии 1.1.0 — Рекламной сети VK (ООО «ВК», SDK myTarget 5.52.5), с версии 1.1.2 — Рекламной сети Яндекса (ООО «Яндекс», Yandex Mobile Ads SDK 8.6.0). Сначала запрашивается реклама Яндекса, если её нет — реклама VK. Видеореклама с наградой показывается только по нажатию игрока на кнопку «x2 за рекламу» на экране результата заезда; бесплатный подарок без рекламы остаётся каждые 5 заездов. Полноэкранная реклама показывается только между заездами (при выходе в меню или магазин), не чаще одного раза в 3 минуты, не раньше чем через 3 минуты после запуска и никогда во время заезда. Баннеров нет.

Обе сети работают в детском режиме: до загрузки рекламы игра сообщает SDK, что пользователь может быть ребёнком (VK: MyTargetPrivacy.setUserAgeRestricted(true); Яндекс: setAgeRestricted(true) и флаг AGE_RESTRICTED_USER в манифесте), не даёт согласия на обработку персональных данных и отключает определение местоположения, поэтому показывается только неперсонализированная реклама. Рекламный идентификатор (Advertising ID) не используется, разрешение на него удалено. Для доставки рекламы и подсчёта показов SDK могут получать технические данные: IP-адрес, модель и версию ОС устройства, язык, сведения о сети и факте показа или нажатия. В составе SDK Яндекса есть служебный компонент AppMetrica; отдельная аналитика приложения через него не включена (APPMETRICA_EASY_INTEGRATION_ENABLED=false, setAppAdAnalyticsReporting(false)). Эти данные обрабатывают ООО «ВК» и ООО «Яндекс» по своим правилам: политика конфиденциальности myTarget, документы Рекламной сети VK, политика конфиденциальности Яндекса, условия использования Yandex Mobile Ads SDK. Встроенных покупок нет.

5. Оценка в RuStore и служебные метрики SDK

С версии 1.1.4 приложение использует официальный RuStore Review SDK (ru.rustore.sdk:review:10.5.1) для показа системного окна оценки приложения. Оценка запрашивается ненавязчиво (после нескольких запусков и удачного заезда, не чаще раза в несколько дней, без наград за оценку). Если системное окно недоступно, игра может предложить открыть страницу приложения в RuStore. Вместе с Review SDK подключается служебный модуль метрик RuStore (ru.rustore.sdk:metrics): он может получать технические данные об устройстве и работе SDK для стабильности и статистики RuStore. Разработчик не получает и не обрабатывает эти данные сам. Подробности — в документах RuStore / VK: справка для разработчиков RuStore, RuStore Review SDK.

6. Дети

Возрастной рейтинг игры — 6+. Разработчик не собирает данные, в том числе данные детей; реклама настроена в детском режиме без персонализации. Нажатие на рекламу может открыть сайт или магазин приложений; если ребёнок играет один, интернет можно выключить — игра полностью работает без него. Ссылки на эту политику и адрес электронной почты для связи находятся только в разделе «Настройки» и открываются только после проверки для взрослых (нужно решить пример на умножение).
