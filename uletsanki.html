Политика конфиденциальности приложения «Улётные санки»

Дата вступления в силу: 01.11.2026

Приложение «Улётные санки» (пакет ru.bulashov.uletsanki) разработано Булашовым Кириллом (далее — разработчик). Эта политика объясняет, какие данные использует приложение.

1. Какие данные собираются

Приложение не собирает, не передаёт и не продаёт персональные данные. Регистрация и вход не требуются.

2. Данные на устройстве

Игровой прогресс (монеты, уровни улучшений, рекорд, выполненные цели) и настройки (музыка, тряска экрана) хранятся только локально на вашем устройстве и никуда не отправляются. Эти данные удаляются кнопкой «Сбросить прогресс» в настройках игры, очисткой данных приложения или его удалением.

3. Разрешения

Начиная с версии 1.1.0 приложение использует разрешения на доступ к интернету и состоянию сети — только для показа рекламы. Без интернета игра работает полностью, просто реклама не показывается. Приложение не запрашивает доступ к камере, микрофону, контактам, местоположению или файлам.

4. Реклама и сторонние сервисы

Начиная с версии 1.1.0 в игре есть реклама Рекламной сети VK (ООО «ВК», SDK myTarget 5.52.5). Видеореклама с наградой показывается только по нажатию игрока на кнопку «x2 за рекламу» на экране результата заезда; бесплатный подарок без рекламы остаётся каждые 3 заезда. Полноэкранная реклама показывается только между заездами (при выходе в меню или магазин), не чаще одного раза в 3 минуты, не раньше чем через 3 минуты после запуска и никогда во время заезда. Баннеров нет. Реклама работает в детском режиме: до загрузки рекламы игра сообщает SDK, что пользователь может быть ребёнком (MyTargetPrivacy.setUserAgeRestricted(true)), и не даёт согласия на обработку персональных данных, поэтому показывается только неперсонализированная реклама; рекламный идентификатор (Advertising ID) не используется, разрешение на него удалено. Для доставки рекламы SDK может получать технические данные: IP-адрес, модель и версию ОС устройства, язык, сведения о сети и факте показа или нажатия. Эти данные обрабатывает ООО «ВК» по своей политике: политика конфиденциальности myTarget, документы Рекламной сети VK. Встроенных покупок и аналитики нет.

5. Дети

Возрастной рейтинг игры — 6+. Разработчик не собирает данные, в том числе данные детей; реклама настроена в детском режиме без персонализации. Нажатие на рекламу может открыть сайт или магазин приложений; если ребёнок играет один, интернет можно выключить — игра полностью работает без него. Ссылки на эту политику и адрес электронной почты для связи находятся только в разделе «Настройки» и открываются только после проверки для взрослых (нужно решить пример на умножение).
