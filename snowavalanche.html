Политика конфиденциальности игры «Снежный ком»

Дата вступления в силу: 7 ноября 2026 г. (версия 1.0.0).

Игра «Снежный ком» (ru.bulashov.snowavalanche) разработана Булашовым Кириллом. Эта политика объясняет, какие данные обрабатывает игра.

Какие данные собираются

Сама игра не собирает, не продаёт и не передаёт разработчику персональные данные. Регистрация не нужна. В игре есть реклама Рекламной сети Яндекса (ООО «Яндекс»), поэтому игре нужен доступ к интернету (разрешения INTERNET и ACCESS_NETWORK_STATE). Без интернета игра работает полностью, просто реклама не показывается, а награды за видео выдаются в подарок.

Данные на устройстве

На вашем устройстве (в локальном хранилище приложения) сохраняются только игровой прогресс: рекорд, монеты, уровень и опыт, улучшения, открытые скины, ежедневные задания, серия входов и сведения о запросе оценки. Для ежедневных заданий и наград за вход игра использует дату на устройстве; дата никуда не передаётся. Эти данные никуда не отправляются и удаляются вместе с приложением или при очистке его данных.

Разрешения

Игра использует разрешения на доступ к интернету и состоянию сети (для рекламы и для работы служб RuStore: оценка и служебные метрики SDK) и на вибрацию (короткий отклик при ударах). SDK оценки RuStore также добавляет разрешение на получение события загрузки устройства (RECEIVE_BOOT_COMPLETED) для своей служебной службы метрик. Игра не запрашивает доступ к камере, микрофону, местоположению, контактам или файлам.

В главном меню есть ссылка на эту политику. Переход из игры на внешние страницы (эта политика и страница игры в RuStore) защищён проверкой для взрослых: нужно решить пример на умножение. Сама игра при этом никаких данных не передаёт.

Реклама

Реклама показывается только Рекламной сетью Яндекса (Yandex Mobile Ads SDK 8.6.0). SDK других рекламных сетей, в том числе Рекламной сети VK (myTarget), в версии 1.0.0 нет. Если в обновлении появится другая рекламная сеть, эта политика будет обновлена до выхода такой версии. Форматов два.

Видео с наградой — только по желанию игрока, по нажатию кнопки:

  • продолжить забег после поражения («Продолжить»);
  • удвоить монеты за забег («Награда x2»);
  • начать забег с лавиной («Старт с лавиной»);
  • получить вторую ежедневную награду за вход.

Награда выдаётся после досмотра ролика. Если рекламу загрузить не удалось (нет сети или подходящих объявлений), награда выдаётся без рекламы.

Полноэкранная реклама — только после окончания забега, при нажатии «Ещё раз» или «В меню», начиная с третьего завершённого забега, не чаще одного раза в 2,5 минуты, не раньше чем через 2,5 минуты после запуска и никогда во время забега.

Баннеров нет. Реклама работает в детском режиме: до загрузки любой рекламы игра сообщает SDK, что пользователь может быть ребёнком (Яндекс: setAgeRestricted(true) и флаг AGE_RESTRICTED_USER в манифесте), не даёт согласия на обработку персональных данных и отключает определение местоположения. Поэтому показывается только неперсонализированная реклама, рекламный идентификатор (Advertising ID) не используется, разрешение на него из приложения удалено. Для доставки рекламы и подсчёта показов SDK может получать технические данные, необходимые для показа объявления: IP-адрес, модель и версию ОС устройства, язык, сведения о сети и факте показа или нажатия. В составе SDK Яндекса есть служебный компонент AppMetrica; отдельная аналитика приложения через него не включена (APPMETRICA_EASY_INTEGRATION_ENABLED=false, setAppAdAnalyticsReporting(false)). Эти данные обрабатывает ООО «Яндекс» по своим правилам: политика конфиденциальности Яндекса, условия использования Yandex Mobile Ads SDK. Разработчик эти данные не получает.

Оценка в RuStore и служебные метрики SDK

Приложение использует официальный RuStore Review SDK (ru.rustore.sdk:review:10.5.1) для показа системного окна оценки приложения. Оценка запрашивается ненавязчиво (после нескольких запусков и завершения забега, не чаще раза в несколько дней, без наград за оценку). Если системное окно недоступно, игра может предложить открыть страницу приложения в RuStore (после проверки для взрослых). Вместе с Review SDK подключается служебный модуль метрик RuStore (ru.rustore.sdk:metrics): он может получать технические данные об устройстве и работе SDK для стабильности и статистики RuStore. Разработчик не получает и не обрабатывает эти данные сам. Подробности — в документах RuStore: справка для разработчиков RuStore, RuStore Review SDK.

Покупки и аналитика

В игре нет встроенных покупок. Сторонние аналитические сервисы не используются (кроме служебных функций рекламных SDK и SDK оценки RuStore, описанных выше).

Возраст

Игра имеет возрастную маркировку 6+. Разработчик не собирает данные о детях и других пользователях; реклама настроена в детском режиме без персональных данных и без персонализации. Нажатие на рекламу может открыть сайт или магазин приложений; если ребёнок играет один, интернет можно выключить — игра полностью работает без него.
