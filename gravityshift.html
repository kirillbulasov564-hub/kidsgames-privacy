1. Какие данные мы собираем

Сама игра не собирает, не продаёт и не передаёт разработчику персональные данные. Регистрация и вход не требуются. Начиная с версии 1.0.2 в игре есть реклама Рекламной сети VK (ООО «ВК»), а с версии 1.0.3 — также Рекламной сети Яндекса (ООО «Яндекс»); технические данные, нужные для показа рекламы, получают ООО «ВК» и ООО «Яндекс» (см. раздел 2).

На устройстве локально сохраняются только прогресс (открытые уровни, звёзды, лучшие результаты, достижения, использованные подсказки), сведения о запросе оценки и настройки. Эти данные удаляются при удалении приложения или кнопкой «Сбросить прогресс» в настройках.

2. Реклама, интернет и покупки

Реклама показывается с помощью SDK двух рекламных сетей: Рекламной сети Яндекса (Yandex Mobile Ads SDK 8.6.0, с версии 1.0.3) и Рекламной сети VK (myTarget 5.52.5, с версии 1.0.2). Сначала запрашивается реклама Яндекса, если её нет — реклама VK. Поэтому игре нужен доступ к интернету (разрешения INTERNET и ACCESS_NETWORK_STATE). Без интернета игра работает полностью, просто реклама не показывается, а подсказка за видео выдаётся в подарок.

Видео с наградой — только по желанию игрока: по кнопке «Подсказка за видео» на уровне. Подсказка выдаётся после досмотра ролика; если рекламу загрузить не удалось (нет сети или подходящих объявлений), подсказка выдаётся без рекламы.

Полноэкранная реклама — только между уровнями, при нажатии «Следующий уровень», не чаще одного раза в 2,5 минуты, не раньше чем через 2,5 минуты после запуска и никогда во время уровня.

Баннеров нет. Обе сети работают в детском режиме: до загрузки любой рекламы игра сообщает SDK, что пользователь может быть ребёнком (VK: MyTargetPrivacy.setUserAgeRestricted(true); Яндекс: setAgeRestricted(true) и флаг AGE_RESTRICTED_USER в манифесте), не даёт согласия на обработку персональных данных и отключает определение местоположения. Поэтому показывается только неперсонализированная реклама, рекламный идентификатор (Advertising ID) не используется, разрешение на него из приложения удалено, сервис аналитики MyTracker не подключён. Для доставки рекламы и подсчёта показов SDK могут получать технические данные, необходимые для показа объявления: IP-адрес, модель и версию ОС устройства, язык, сведения о сети и факте показа или нажатия. В составе SDK Яндекса есть служебный компонент AppMetrica; отдельная аналитика приложения через него не включена (APPMETRICA_EASY_INTEGRATION_ENABLED=false, setAppAdAnalyticsReporting(false)). Эти данные обрабатывают ООО «ВК» и ООО «Яндекс» по своим правилам: политика конфиденциальности myTarget, документы Рекламной сети VK, политика конфиденциальности Яндекса, условия использования Yandex Mobile Ads SDK. Разработчик эти данные не получает.

Встроенных покупок нет. Сторонние аналитические сервисы не используются (кроме служебных функций рекламных SDK и SDK оценки RuStore, описанных ниже).

3. Оценка в RuStore и служебные метрики SDK

С версии 1.0.3 приложение использует официальный RuStore Review SDK (ru.rustore.sdk:review:10.5.1) для показа системного окна оценки приложения. Оценка запрашивается ненавязчиво (после нескольких запусков и прохождения уровня, не чаще раза в несколько дней, без наград за оценку). Если системное окно недоступно, игра может предложить открыть страницу приложения в RuStore. Вместе с Review SDK подключается служебный модуль метрик RuStore (ru.rustore.sdk:metrics): он может получать технические данные об устройстве и работе SDK для стабильности и статистики RuStore. Разработчик не получает и не обрабатывает эти данные сам. Подробности — в документах RuStore / VK: справка для разработчиков RuStore, RuStore Review SDK.

4. Разрешения

Приложение использует разрешения на доступ к интернету и состоянию сети (для рекламы и для работы служб RuStore: оценка и служебные метрики SDK). SDK оценки RuStore также добавляет разрешение на получение события загрузки устройства (RECEIVE_BOOT_COMPLETED) для своей служебной службы метрик. Приложению не нужны камера, микрофон, контакты, геолокация и уведомления.

5. Возраст

Игра имеет возрастную маркировку 6+. Разработчик не собирает данные о детях и других пользователях; реклама настроена в детском режиме без персональных данных и без персонализации.
