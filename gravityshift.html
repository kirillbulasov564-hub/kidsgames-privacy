Политика конфиденциальности

Приложение: «Гравитационный сбой» (пакет ru.bulashov.gravityshift)
Разработчик: Кирилл Булашов
Контакт: bulashovki@outlook.com
Дата вступления в силу: 15 октября 2026 г.
Обновлено: 1 ноября 2026 г. (версия 1.0.2)

1. Какие данные мы собираем

Сама игра не собирает, не продаёт и не передаёт разработчику персональные данные. Регистрация и вход не требуются. Начиная с версии 1.0.2 в игре есть реклама Рекламной сети VK (ООО «ВК»); технические данные, нужные для показа рекламы, получает только ООО «ВК» (см. раздел 2).

На устройстве локально сохраняются только прогресс (открытые уровни, звёзды, лучшие результаты, достижения, использованные подсказки) и настройки. Эти данные удаляются при удалении приложения или кнопкой «Сбросить прогресс» в настройках.

2. Реклама, интернет и покупки

Реклама показывается с помощью SDK Рекламной сети VK (myTarget), поэтому игре нужен доступ к интернету. Без интернета игра работает полностью, просто реклама не показывается.

Видео с наградой — только по желанию игрока: по кнопке «Подсказка за видео» на уровне. Подсказка выдаётся после досмотра ролика; если рекламу загрузить не удалось (нет сети или подходящих объявлений), подсказка выдаётся без рекламы.

Полноэкранная реклама — только между уровнями, при нажатии «Следующий уровень», не чаще одного раза в 2,5 минуты, не раньше чем через 2,5 минуты после запуска и никогда во время уровня.

Баннеров нет. Реклама работает в детском режиме: до загрузки любой рекламы игра сообщает SDK, что пользователь может быть ребёнком (MyTargetPrivacy.setUserAgeRestricted(true)), и не даёт согласия на обработку персональных данных. Поэтому показывается только неперсонализированная реклама, рекламный идентификатор (Advertising ID) не используется, разрешение на него из приложения удалено, сервис аналитики MyTracker не подключён. Для доставки рекламы SDK может получать технические данные, необходимые для показа объявления: IP-адрес, модель и версию ОС устройства, язык, сведения о сети и факте показа или нажатия. Эти данные обрабатывает ООО «ВК» по своей политике: политика конфиденциальности myTarget, документы Рекламной сети VK. Разработчик эти данные не получает.

Встроенных покупок нет. Сторонние аналитические сервисы не используются.

3. Разрешения

Приложение использует разрешения на доступ к интернету и состоянию сети (только для рекламы). Приложению не нужны камера, микрофон, контакты, геолокация и уведомления.

4. Изменения

Если политика изменится, обновлённый текст будет опубликован по этой же ссылке. Вопросы: bulashovki@outlook.com.
